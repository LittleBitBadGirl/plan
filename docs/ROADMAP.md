## 🎯 Новые задачи (Приоритет)

### 1. Рефакторинг Трекеров (Календарная сетка)
- **Цель:** Сделать сетку трекеров интуитивно понятной, привязав её к дням недели.
- **Логика:** Если старт 30.04 (четверг), то на первой неделе пропускаем Пн, Вт, Ср.
- **Визуал:** Сетка 7 колонок (дни недели) вместо 10.
- **Результат:** Четкое понимание "какой сегодня день курса" без путаницы с числами месяца.

### 2. Мобильная версия и Desktop
- **Цель:** Удобное использование на Android и большом экране.
- **Адаптивность:** Подправить CSS, чтобы на телефоне кнопки были крупнее, а списки не сжимались.
- **Android Shortcut:** Инструкция по выносу иконки "Planner" на главный экран телефона (PWA-like).

### 3. Автодеплой (GitHub -> VPS)
- **Цель:** Обновление сервера одной командой `git push`.
- **Инструмент:** GitHub Actions.
- **Статус:** Ждем расширения диска на VPS.
