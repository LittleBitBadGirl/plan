## Поток задач (блок `partials/stats_flow.html`)

`get_flow_data(db, period)` из `deps.py` — единственный источник чисел блока:

- **Прилетело:** `_created_base_filter` + `created_flow` — корневые задачи (`parent_task_id IS NULL`), `item_kind='task'`, не `recurring`, по ЛОКАЛЬНЫМ суткам. Архивность не влияет: прилёт — факт появления. Второе число — из прилетевшего закрыто в тот же день.
- **Закрыто:** `completed_counts_by_local_day` — то же определение, что у карточек (одно на всю страницу).
- Окна из ПОЛНЫХ дней: неделя 7 дней, месяц 30, год 12 полных месяцев; сегодняшний неполный день не входит.
- График: в каждом дне два столбика (закрыто / прилетело) на ОДНОЙ шкале (общий максимум). В году подписи только у первых чисел месяца.
- Бакеты недель/месяцев: общая шкала на два ряда, у неполной крайней недели стоит число дней («·Nд»).

## Инсайты под графиком

`get_productivity_insights(db)`:

| Метрика | Логика |
|---------|--------|
| Ср. темп | `get_avg_completed_per_day(14)` — только пн–пт в числителе и знаменателе |
| 7 / 30 дней | `count_completed_tasks(..., workdays_only=True)` |
| Δ неделя | текущее 8-дневное окно vs предыдущее 8-дневное (`rolling_week_windows`) |
| Рекорд нед. | max по рабочим дням из week history |
| Темп нед. % | `completed_7d / round(avg * workdays_7) * 100` |
| Зависли | `status == в_работе`, корневая, не архив, `created_at <= now-7d` (нет поля смены статуса) |

Вспомогательные: `is_weekend`, `count_workdays_between`, `_sqlite_completed_not_on_weekend` (%w: 0=вс, 6=сб).
