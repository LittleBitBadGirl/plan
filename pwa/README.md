# Planner PWA — офлайн-режим

Офлайн-слой планера: с телефона без интернета можно **добавлять, изменять и
удалять задачи**, а при появлении связи всё уходит на сервер. Изменения, которые
за это время появились в планере, не затираются: сервер сливает правки по полям,
а спор по одному и тому же полю выносится на решение — «оставить в планере» или
«поставить моё».

Границы: офлайн правятся **только задачи** (дашборд, бэклог, архив, подзадачи).
Формы остальных разделов без сети не гасятся молча — плашка говорит, что нужен
интернет.

Архитектура и обоснования решений: `ARCHITECTURE.md`.

## Файлы

| Файл | Куда отдаётся | Назначение |
|---|---|---|
| `sw.js` | `/sw.js` (роут в `app/main.py`, заголовок `Service-Worker-Allowed: /`) | Кэш и офлайн-отдача страниц, статики, API |
| `offline.js` | `/pwa/offline.js` (монтирование каталога `pwa/` в `app/main.py`) | Срез задач, очередь правок, слияние, плашка, разбор конфликтов |
| `offline.html` | `/pwa/offline.html` | Заглушка «нет сети» со списком сохранённых страниц |

Подключение к страницам — одна строка в `app/web/templates/base.html`:

```html
<script defer src="/pwa/offline.js"></script>
```

Серверная часть:

| Файл | Что там |
|---|---|
| `app/api/offline.py` | `/api/offline/state`, `/api/offline/sync`, `/api/offline/conflicts` |
| `app/services/offline_sync_service.py` | Применение действий, слияние полей, конфликты |
| `app/models/offline.py` | Таблицы `offline_actions` (журнал, ключ идемпотентности) и `offline_conflicts` |
| `alembic/versions/011_offline_sync.py` | Миграция этих таблиц |

## Что нужно для работы офлайна

1. **HTTPS.** Service worker регистрируется только в защищённом контексте. По
   `http://<IP>` офлайн-режим не включится вообще: нужен домен с сертификатом
   (Nginx Proxy Manager + Let's Encrypt). Исключение — `http://localhost`.
2. **Установка на телефон:** Chrome на Android → меню → «Добавить на главный
   экран». После этого планер открывается как приложение, без адресной строки.
3. Первый заход должен быть **онлайн** — иначе нечего сохранять в кэш и нет среза
   задач, с которым сравнивать правки.

## Изменение версии

1. Поднять `VERSION` в `sw.js` (`planner-pwa-v2` → `planner-pwa-v3`).
2. Запушить. При следующем визите service worker скачает новую версию и удалит
   старые кэши на активации; в плашке появится кнопка «Обновить».
3. Если у Веры залипла старая версия: «Настройки сайта → Данные сайта → Очистить»
   либо повторное открытие приложения.
