## ✅ Что работает (Final State)

1. **Vision AI (Bot):**
   - Бот "видит" фото напрямую. Используется модель `llama-4-scout-17b`.
   - Автоматически сжимает тяжелые скриншоты до 2000px/JPEG (Pillow).
   - Извлекает траты из банковских приложений (Альфа, Т-Банк) с правильными знаками (+ для расходов).
   - Понимает текущий год (2026).
   - Фолбэк: если ИИ не уверен, скриншот летит в БД `screenshots` (можно разобрать в вебе).

2. **Карьерный капитал:**
   - Поля `impact_notes` и `is_milestone` добавлены в схему.
   - База обновляется автоматически (init_db) при каждом деплое.

3. **Стабильность:**
   - Исправлены ошибки в HTMX (теперь удаление и завершение задач возвращают правильные HTTP-коды).
   - Бэклог защищен от случайного удаления (используется архив).

## 🛠 Технический Handover
- **AI Stack:** Groq API (Llama 3.3 70B для текста, Llama 4 Scout для фото).
- **Backend:** FastAPI + SQLAlchemy.
- **Frontend:** HTML + Tailwind + HTMX.
- **Server:** Docker Compose на Ubuntu (91.186.217.66).
