## ✅ Что работает (Новое в этой версии)

### 💰 Финансовый блок (Professional Edition)
- **📊 Сводка 3-го уровня:** Группировка трат: Месяц -> Группа (Дом/Еда) -> Категория (Ипотека/Табак). Схлопнутый вид для компактности.
- **🎯 Стратегические цели:** Интерактивные прогресс-бары для ИИС (10М), Автомобиля (1.5М) и Подушки (500к). Авто-расчет из транзакций.
- **💸 Гибкий учет:** Доходы записываются со знаком "-", расходы — "+". Автоматический расчет остатка месяца (цветовая индикация).
- **📝 Ручной ввод:** Полноценное модальное окно для записи трат с выбором категории.

### 🤖 Telegram Бот (AI Enhanced)
- **📸 Smart OCR:** Распознавание чеков через Groq (Llama 3). Авто-извлечение суммы, даты и описания.
- **🛡️ Правила Categorization:** Внедрены правила из `fin_budget` (Озон -> Вещи, Татнефть -> Табак/Бензин, БКС -> Подушка).
- **🏷️ AI Тегирование:** Автоматическое выделение людей и проектов (#Антон, #Сбер) из текста задач.
- **⏰ Morning Push:** Авто-рассылка плана на день в 09:00 через APScheduler.

### 🎨 Интерфейс и UX
- **🏗️ Новая архитектура задач:** Кнопки действий перенесены вниз, заголовки на всю ширину (меньше двухстрочных блоков).
- **📈 Global Progress:** Прогресс-бар дня перенесен в шапку (header).
- **📂 Чистые категории:** Разделение "миров" Задач и Финансов. Финансовые категории вынесены в отдельный блок.
- **📅 Smart Calendar:** Выбранная дата отображается прямо в заголовке списка дел.

## 🚀 Деплой
- **Database:** `planner.db` в гитигноре. На сервер переносится вручную или через скрипт импорта.
- **Tests:** `pytest tests/` — обязательный прогон перед любыми изменениями.

- **🐳 Docker:** Добавлены `Dockerfile` и `docker-compose.yml` для развертывания на VPS.
- **📂 Умные счетчики категорий:** Глобальные категории теперь суммируют задачи из всех своих подкатегорий. В интерфейсе добавлены индивидуальные счетчики для каждой подкатегории.
- **🛡️ Гибкие периодические задачи:**
    - Ослаблена проверка на дубликаты: теперь можно создавать задачи с одинаковым именем в разных категориях.
    - Умное скрытие на дашборде теперь учитывает связку «Название + Категория».
    - Исправлена ошибка, блокирующая создание новых шаблонов при наличии неактивных старых.
- **🔄 Умная синхронизация:** При клике на выполнение в «Периодических» система находит и закрывает соответствующую активную задачу в списке (с учетом категории).
- **🛠️ HTMX обновления:** Исправлено обновление списка задач через HTMX (добавлена загрузка подзадач).

### 📊 Статистика и Аналитика (Обновлено)
- **📈 Мульти-периоды:** Добавлена возможность переключения графиков (Неделя / Месяц / Год).
    - Неделя/Месяц: Столбчатая диаграмма по дням.
    - Год: Точечный SVG-график с группировкой по месяцам.
- **🛠️ Честный подсчет:** Статистика (все счетчики и графики) теперь учитывает как основные задачи, так и подзадачи.
- **✨ Динамический AI отчет:** Исправлена ошибка жесткой привязки даты. Теперь инструкция для Gemini и сам анализ формируются динамически за актуальный вчерашний день.
- **📊 API для отчетов:** Добавлен эндпоинт `/api/ai/save-report` для сохранения аналитики прямо в БД.
- **🐞 Исправления:** Устранены ошибки `TypeError` при переносе задач (rollover) и `SyntaxError` в роутах статистики.

### 🏠 Быт и покупки
- **🌗 Разделение страницы:** Вкладка «Покупки» заменена на «Быт и покупки». Слева — список продуктов, справа — блок домашних дел.
- **📋 Быстрый ввод:** Поддержка категорий «Семья», «Быт» и «Покупки» с мгновенным добавлением в нужную колонку.

### 💰 Финансовый учет (из fin_budget)
- **📅 Правило Даты:** Всегда отдаем приоритет дате совершения операции из чека/скриншота. Банковские выписки часто имеют "сдвинутые" даты (дебет через 2-3 дня), поэтому OCR парсинг чека — основной источник правды.
- **🏷️ Категоризация:** Сохранена структура категорий. Доходы записываются со знаком "минус" в поле `amount` для упрощения баланса.
- **🚬 Авто-метки:** Учет трат на сигареты (240/255) теперь заменен на полноценный AI-парсинг чеков.

## 🚀 План деплоя на сервер (VPS)
1. **Docker:** `docker-compose up -d --build`.
2. **Database:** SQLite файл `planner.db` прокидывается через Docker Volume. 
   - *Важно:* Так как БД в гитигноре, при первом деплое нужно либо прогнать `import_fin_data.py` на сервере, либо вручную скопировать файл `.db` в папку проекта на VPS.
3. **Reverse Proxy:** Nginx Proxy Manager для SSL.
